# assets/

Shared static assets used across documentation and applications — for example, the OSSmith logo, brand marks, and architecture diagrams referenced from the docs.

**Status:** Empty as of Sprint 1. Brand and diagram assets will be added as they're finalized.

## Conventions (once populated)

- Prefer SVG for logos and diagrams where possible.
- Keep filenames lowercase, hyphen-separated (e.g. `ossmith-logo-dark.svg`).
- Large binary assets (e.g. video) should be avoided in this repo; link externally instead.
